## 2. 한 판의 흐름 (목표)

1. 거점에서 캐릭터를 고르고 출발한다.
2. 전투 방에 들어가면 적이 웨이브로 나온다. 다 쓰러뜨리면 방 정리.
3. 보상을 하나 고른다(공격력, 스킬 강화, 회복 등). 다음 방으로 간다.
4. 중간에 중간 보스, 끝에 마지막 보스. 지면 거점으로 돌아가고, 얻은 재화로 영구 성장한다.

1차 목표(M1)는 이 중 **전투 방 하나**입니다(§6).

## 3. 전투

### 3.1 공통 규칙
- **기본 공격:** 왼쪽 클릭을 이어 누르면 5단계 연속 공격. 마지막 단계(마무리 일격)는 경직을 크게 쌓고 SP를 조금 돌려준다.
- **대시 공격:** 회피 직후에 공격하면 멀리 내달리며 벤다.
- **배틀 스킬:** SP 100을 쓴다. SP는 최대 300(세 칸), 저절로 찬다(초당 8).
- **궁극기:** 궁극기 에너지가 차면 쓴다(관리자 80). 에너지는 맞히거나 스킬을 쓰거나 맞으면 찬다. 쓰는 동안 무적.
- **회피:** 이동 방향으로 내닫는다(입력이 없으면 뒤로 물러남). 앞부분 0.3초 무적. 적의 공격을 무적으로 피하면 **완벽한 회피**: SP 25를 얻고, 혼자 할 때는 잠깐 느려진다. 회피 뒤에 회피 키를 누르고 있으면 질주.
- **공격 보조:** 공격하면 가까운 적 쪽으로 몸을 돌린다. 대상 고정(휠 클릭)하면 카메라가 그 적을 따라간다.
- **경직:** 적은 경직 게이지가 있고, 다 차면 몇 초 동안 경직된다(움직이지 못하고 받는 피해 1.3배). 경직된 적 가까이서 공격하면 **처형**(크게 다침, 무적).
- **원석 결정:** 관리자의 배틀 스킬에 맞은 적에게 결정이 붙는다(15초). 궁극기 마지막 타격이 결정을 깨뜨리면 큰 추가 피해와 경직.
- **맞기:** 강한 공격(중장병 등)에 맞으면 휘청인다(스킬 중에는 버틴다). 체력이 0이 되면 쓰러지고, 동료가 F를 2.5초 누르고 있으면 체력 30%로 일어난다. 모두 쓰러지면 전멸, 방을 처음부터 다시 한다.

### 3.2 관리자 (여·남)
원작의 칼 동작을 그대로 쓴다. 공격마다 원본 동작에서 **타격 시각**과 **내디디는 거리**를 재서 넣었다(`data/characters/*/kit.tres`). 여·남은 동작 길이와 타격 시각만 다르고 성능은 같다.

| 동작 | 내용 |
|---|---|
| 기본 공격 1~5 | 공격력 배율 0.8 / 0.9 / 0.6+0.8 / 0.6+0.9 / 2.2 |
| 대시 공격 | 1.6배, 약 4m 내달림 |
| 처형 | 0.6 + 0.6 + 5.0배, 무적 |
| 배틀 스킬: 결정 베기 | SP 100, 2.6배, 앞쪽 넓은 부채꼴, **원석 결정을 붙인다** |
| 궁극기: 결정 파쇄 | 에너지 80, 3.0배 + 6.0배, 앞쪽 7m 부채꼴, **결정을 깨뜨려 4배 추가** |

### 3.3 적 (임시 모습)
적은 모두 **예고**한다: 땅에 맞을 자리(부채꼴·원·직선)가 깔리고 맞는 순간까지 차오른다. 예고가 끝나는 순간 회피하면 된다.

| 적 | 역할 | 특징 |
|---|---|---|
| 돌격병 | 근접 | 다가와 벤다. 맞으면 움찔해서 공격이 끊긴다 |
| 사수 | 원거리 | 9m쯤 거리를 두고 탄을 쏜다. 붙으면 밀쳐 낸다 |
| 중장병 | 덩치 | 움찔하지 않는다. 주위를 내려찍기(원), 앞을 쓸기. 맞으면 휘청인다 |

적 모델은 아직 없다(도형으로 그린다). 엔드필드 적 모델을 받으면 `EnemyData.model_file`과 `clips`에 넣는다.

## 4. 조작 (엔드필드 PC판 기본값)

| 키 | 동작 |
|---|---|
| WASD, 마우스 | 이동(카메라 기준), 카메라 돌리기. 휠로 거리 |
| 마우스 왼쪽 | 공격 (경직된 적 가까이서는 처형, 회피 직후는 대시 공격) |
| 마우스 오른쪽 / Shift | 회피 (누르고 있으면 질주) |
| 1 | 배틀 스킬. 궁극기 에너지가 차 있으면 **길게 눌러 궁극기** |
| Q | 궁극기 (엔드필드에는 없지만 캐릭터가 한 명이라 하나 더 둠) |
| 마우스 가운데 | 대상 고정 |
| Space | 점프 |
| F (누르고 있기) | 쓰러진 동료 일으키기 |
| H | 바이저 쓰기/벗기 |
| Esc | 메뉴 |

## 5. 협동
- 같은 와이파이(LAN)에서 최대 3명. 각자 고른 캐릭터로 들어온다.
- 이동과 동작은 각자 계산하고(반응성), **피해 판정은 호스트**가 한다. 내 공격의 맞힌 느낌(멈춤·흔들림·불꽃)은 바로 보여 주고, 피해 숫자는 호스트의 결과로 띄운다.
- 아군 피해 없음. 완벽한 회피의 느린 시간은 혼자 할 때만(남의 시간까지 늦출 수 없다).
