# 검수 체크리스트: 설정

자동 테스트 105개가 모두 통과한 상태입니다. 메인 메뉴의 **설정** 버튼이나, 게임 중 Esc → **설정**으로 엽니다.
바꾼 값은 바로 적용되고, 닫을 때 저장됩니다(`%APPDATA%\Godot\app_userdata\CyberUniverse\settings.cfg`).

## 들어 있는 설정
| 탭 | 항목 |
|---|---|
| 소리 | 전체 음량, 음악, 효과음, 음성, 인터페이스 (0~100%, 0이면 음소거) |
| 화면 | 창 모드(창 / 테두리 없는 전체 화면 / 전체 화면), 창 크기, 수직 동기화, 최대 프레임, 글자·메뉴 크기, 밝기 |
| 그래픽 | 렌더링 해상도(50~100%), 안티에일리어싱(끄기 / FXAA / MSAA 2배 / 4배), 그림자 품질(낮음 / 보통 / 높음) |
| 조작 | 마우스 감도, 상하 반전, 시야각(60~110°), 누르는 방식(웅크리기·달리기·조준·자유 시야를 토글/누르는 동안), 입력 설정 18개(키보드 키와 마우스 버튼 모두 지정 가능) |
| 게임 | 시작 시점(1인칭 / 3인칭), 바이저 쓰기, 자동 업데이트 켜기·끄기, 에셋 키(캐릭터 모델 자동 업데이트) |

## 확인할 것
- [ ] 소리 막대를 움직였다 놓으면 "삑" 확인음이 그 크기로 나는가 (게임에는 아직 소리가 없습니다)
- [ ] 창 모드와 창 크기를 바꾸면 바로 바뀌는가. 다시 켜도 그대로인가
- [ ] 글자·메뉴 크기를 키우면 메뉴와 HUD가 커지는가
- [ ] 밝기를 올리면 시험장이 밝아지는가 (게임 중 Esc → 설정에서 바로 확인)
- [ ] 마우스 감도, 상하 반전, 시야각이 게임에 바로 반영되는가
- [ ] 키 설정: 버튼을 누르고 새 키나 마우스 버튼을 누르면 바뀌는가. 다른 동작이 쓰던 입력을 고르면 서로 바뀌는가
- [ ] 공격·조준·무기 휠도 다른 키나 마우스 버튼으로 바꿀 수 있는가
- [ ] 달리기를 토글로 바꾸면 한 번 눌러 계속 달리고, 멈추면 풀리는가. 조준 토글은 한 번 눌러 유지되는가
- [ ] Esc: 키를 바꾸는 중이면 취소, 아니면 설정 창이 닫히는가
- [ ] "기본값으로"를 누르면 모두 처음 값으로 돌아가는가
- [ ] 게임 → "바이저 쓰기"를 끄고 설정을 닫으면 내 캐릭터가 바이저를 벗는가. 다음에 켜도 그대로인가
- [ ] 게임 → "에셋 키"에 토큰을 붙여 넣으면 글자가 가려지는가. 다음에 켤 때 메인 메뉴에 "새 캐릭터 모델을 받았습니다"가 뜨는가(모델이 바뀌었을 때만)

## 제가 임의로 정한 것 (바꾸고 싶으면 알려 주세요)
| 항목 | 지금 정한 값 | 이유 |
|---|---|---|
| 기본 음량 | 전체·효과음·음성 100%, 음악·인터페이스 80% | 음악과 메뉴 소리가 효과음을 덮지 않게 |
| 기본 안티에일리어싱 | FXAA | 가볍고 대부분의 PC에서 무리가 없음 |
| 기본 그림자 | 보통 | 품질과 속도의 중간 |
| 바꿀 수 없는 입력 | 회피(방향키 두 번), 일시정지(Esc), 디버그(F3) | 회피는 이동 키를 따르고, Esc는 메뉴를 닫는 데도 쓰여 고정했습니다 |
| 달리기 토글 | 앞으로 가지 않으면 풀림 | 사이버펑크 2077과 같은 방식 |
| 조준 토글 | 달리기 시작하면 풀림 | |
| 키 겹침 | 서로 맞바꿈 | 한 키가 두 동작에 묶여 헷갈리는 일을 막습니다 |
| 바이저 키 | H | 사이버펑크 2077에는 없는 동작이라 비어 있는 H(Head)를 썼습니다 |
| 에셋 키 | 설정 파일(`settings.cfg`)에 그대로 저장 | 가족 PC용이라 따로 암호화하지 않았습니다. 그 저장소 읽기 전용 토큰만 넣어 주세요 |
