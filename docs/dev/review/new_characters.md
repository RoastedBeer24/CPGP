# 검수 체크리스트: 진천우·아크라이트·포그라니치니크 추가

> 로비에서 **C**(캐릭터 화면)를 열고 아래쪽 아이콘 줄에서 고르세요. 사용자가 준 꾸러미
> (`!File/Chen_Arclight_Pogranichnik_Complete_Assets.zip`)의 모델·동작·전용 무기·소리·보이스·이펙트·궁극기 카메라를 씁니다.
> 세 캐릭터는 아직 초상화가 없어 아이콘이 이름 첫 글자입니다(초상화를 주시면 넣습니다).

| 캐릭터 | 원작 | 기본 공격 | 배틀 스킬 | 대시 공격(연계 스킬) | 궁극기 | 전용 무기 |
|---|---|---|---|---|---|---|
| 진천우 | chr_0005_chen | 파비하 5연속 | 귀궁우 | 견천하 | 예풍상 | 숭배의 시선 |
| 아크라이트 | chr_0007_ikut | 추적 사냥 5연속 | 질풍 섬광 | 천둥의 울림 | 천둥번개 | 십이문 |
| 포그라니치니크 | chr_0029_pograni | 전면 공세 5연속 | 전선 분쇄 | 보름달 참격 | 방패병 부대, 전진 | 끝없는 방랑 |

## 모습
- [ ] 세 캐릭터가 원작처럼 보이는가 (만화풍 그늘, 외곽선, 얼굴 그림자, 진천우의 뿔, 포그라니치니크의 방패)
- [ ] 캐릭터 화면이 원작 구도이고 걸어 들어오기·대기·쓰다듬기 반응·무기 보기(W)가 나오는가
- [ ] 겹쳐 그려진 메시나 이상한 줄무늬가 없는가

## 싸움
- [ ] 기본 공격 5연속이 끊김 없이 이어지고, 칼이 적에 닿는 순간 맞는가 (타격 시각은 원작 동작에서 잰 값)
- [ ] 회피 직후 공격하면 원작 연계 스킬(견천하·천둥의 울림·보름달 참격)이 나가는가
- [ ] 배틀 스킬(1)과 궁극기(Q)가 원작 이펙트·소리·보이스와 함께 나오고, 궁극기에서 원작 카메라 연출이 나오는가
- [ ] 처형(경직된 적 가까이서 공격)과 낙하 공격(점프 뒤 공격)이 어색하지 않은가
- [ ] 걷기·달리기·질주·회피·점프가 어색하지 않은가 (포그라니치니크는 원작의 남성 공통 동작)
- [ ] 무기는 싸우는 동작에서만 오른손에 나타나는가 (포그라니치니크는 처형·배틀 스킬·궁극기 앞부분에 칼을 거두고 방패로 싸운다)
- [ ] 1인칭(V)에서 시점이 각자 눈에 있고 몸이 보이는가

## 무기
- [ ] 무기 목록에 한손검 다섯(타르 11, 엣지 오브 라이트, 숭배의 시선, 십이문, 끝없는 방랑)이 있고 모든 검 캐릭터가 바꿔 들 수 있는가

## 7차 고침 (사용자 지적)
- [ ] 궁극기를 쓴 뒤 카메라가 높은 곳에서 내려다보는 채로 남지 않고 원래 자리로 부드럽게 돌아오는가 (아크라이트·포그라니치니크)
- [ ] 포그라니치니크가 배틀 스킬·처형·궁극기 동안 칼을 거두고 왼손에 원작 소품(wpn_misc_0035)을 들고 싸우다가 칼을 다시 드는가
- [ ] 진천우가 왼손에 칼집(wpn_misc_0002)을 들고, 허리에 장식(wpn_misc_0003)을 다는가
- [ ] 아크라이트의 대시 공격(천둥의 울림)과 배틀 스킬(질풍 섬광), 포그라니치니크의 대시 공격(보름달 참격)에 원작 소리·이펙트가 나오는가 (예전에는 소리·이펙트가 없는 다른 동작이었다)
- [ ] 1인칭에서 공격·스킬·회피 같은 격한 동작 중에 몸이 화면을 가득 덮거나 시점이 몸속에 묻히지 않는가

| 7차에 제가 정한 것 | 정한 값 | 바꾸려면 |
|---|---|---|
| 아크라이트 동작 | 연계 스킬 normal_skill02, 배틀 스킬 normal_skill03 (원작 battle.json) | `tools/extract_character.py`의 `ROLE_OVERRIDES` |
| 포그라니치니크 대시 공격 | combo_skill_03 (원작 battle.json의 연계 스킬) | 같은 곳 |
| 소품 | 원작 무기 연결 정보의 둘째 무기부터: 진천우 칼집·장식(평소에도 보임), 포그라니치니크 왼손 소품(스킬 동안만) | `tools/extract_character_fx.py`의 `PROPS` |
| 궁극기 컷 되돌아오기 | 원작 자료가 0이어도 0.35초 동안 섞어 돌아옴 | `Player.SHOT_MIN_EASE_OUT` |
| 1인칭 격한 동작 | 시점을 처음 자세의 눈 자리로 모으고 0.35m까지만 내려감, 숙이기 끔, 카메라 0.25~0.5m 안의 몸을 점점이 지움 | `PlayerBody.FIRST_PERSON_ACTION_DIP`, `VIEW_ACTION_FADE_*` |
| 포그라니치니크 궁극기 방패 | 방패병 자리(Spawn01~04)의 방패는 아직 그리지 않음 | - |

## 8차 고침 (사용자 지적: 캐릭터 바꿀 때 렉, 적 순간이동, 소품, 기본 개선)
설치된 게임은 켤 때 새 에셋(구운 모델 `.scn`, 약 470MB)을 한 번 받습니다. 받은 뒤에 확인해 주세요.
- [ ] 캐릭터 화면(C)에서 캐릭터를 이것저것 바꿔도 게임이 멈칫하지 않는가 (게임을 켜고 몇 초 지나면 모든 캐릭터·적·무기를 배경에서 미리 읽어 둔다. 예전에는 처음 고른 캐릭터마다 2~3초 멈췄다)
- [ ] 처음 전투 방에 들어갈 때와 처음 스킬·궁극기를 쓸 때도 멈칫하지 않는가
- [ ] 적이 공격할 때 원작 동작처럼 다가서거나 뛰어들고, 맞는 순간 확 튀어 나가지 않는가 (돌진도 천천히 빨라진다)
- [ ] 몸을 크게 돌리는 적 공격(처형자·로댄)이 끝날 때 휙 돌아가지 않고 자연스럽게 돌아오는가
- [ ] 때렸을 때 적이 확 튀지 않고 부드럽게 밀리는가
- [ ] 협동에서 손님 쪽 화면의 적이 띄엄띄엄 움직이지 않는가
- [ ] 포그라니치니크의 왼손 소품이 칼처럼 손잡이부터 차오르고, 거둘 때 끝부터 지워지는가 (예전에는 툭 나타나고 사라졌다)
- [ ] 진천우가 오래 서 있어 쉬는 자세가 되면 칼집과 허리 장식을 거두는가 (원작 캐릭터 화면 자료대로)
- [ ] 포그라니치니크의 긴 외투와 진천우의 치마가 달릴 때 뒤로 흔들리고, 다리를 뚫지 않는가
- [ ] 진천우·아크라이트·포그라니치니크의 꼬리(아크라이트는 귀, 포그라니치니크는 머리 깃털도)가 몸놀림에 따라 흔들리는가
- [ ] 캐릭터 모습(텍스처)이 예전과 같은가 (큰 텍스처를 BC7로 압축해 그래픽 메모리를 약 4분의 1로 줄였다)
