# M1 검수 체크리스트: 플레이어 컨트롤러 + 네트워크 뼈대

시간 날 때 직접 해 보시고, 이상하거나 손맛이 어색한 부분을 알려 주세요. 자동 테스트는 모두 통과한 상태입니다(38개).

## 준비
1. Godot 4.5.1 **표준판**으로 `project.godot`를 엽니다. 브랜치는 `ccr-4caca829-oaex8d`입니다.
2. F5를 누르면 메인 메뉴가 나옵니다.

## 조작 (사이버펑크 2077 기본값)
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 |
| Shift (누르고 있기) | 달리기 |
| Ctrl 또는 C | 웅크리기 (토글) |
| 달리는 중 Ctrl | 슬라이딩 |
| Space | 점프 |
| 턱을 향해 Space를 누른 채 앞으로 | 턱 오르기 |
| Esc | 메뉴 |
| F3 | 디버그 표시 (상태, 속도, FPS) |

## 1. 혼자 하기
메인 메뉴에서 **혼자 하기**를 누릅니다.

시험장 구성 (시작 위치에서 앞을 보고):
- **정면의 주황색 턱 5개:** 높이 0.5m부터 2.5m까지. 주황색은 "오를 수 있는 곳"이라는 표시입니다.
- **오른쪽:** 25도 경사로와 높이 3m 옥상 두 개. 옥상 사이 틈은 3.5m입니다.
- **왼쪽:** 계단과 옥상
- **왼쪽 안쪽:** 천장 높이 1.3m 터널
- **근처의 회색 상자:** 엄폐물 크기의 장애물

확인할 것:
- [ ] 걷기, 달리기 속도가 적당한가 (걷기 4m/s, 달리기 6.8m/s)
- [ ] 마우스 감도가 적당한가
- [ ] 점프 높이와 체공 시간이 자연스러운가
- [ ] 달리다 Ctrl로 슬라이딩이 시원하게 나가는가
- [ ] 주황색 턱 5개를 모두 오를 수 있는가. 오르는 동작이 답답하지 않은가
- [ ] 계단과 경사로로 옥상에 오를 수 있는가
- [ ] 옥상 사이 3.5m 틈을 달리기 점프로 건널 수 있는가
- [ ] 터널 안에서 웅크린 상태로 일어서려 하면 일어서지 않는가
- [ ] Esc를 누르면 게임이 멈추고, "계속하기"로 돌아오는가

## 2. 코옵 (PC 두 대 이상, 같은 와이파이)
1. 한 PC에서 **방 만들기**를 누릅니다.
2. Esc를 누르면 **방 주소**(예: `192.168.0.12`)가 보입니다.
3. 다른 PC에서 그 주소를 입력하고 **참여하기**를 누릅니다.
4. 처음 방을 만들 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 눌러 주세요. 포트는 UDP 47820입니다.

확인할 것:
- [ ] 서로의 캐릭터(분홍색 캡슐, 청록색 눈 부분)가 보이는가
- [ ] 상대가 움직이고, 고개를 돌리고, 웅크리는 모습이 자연스럽게 따라오는가
- [ ] 세 번째 사람도 들어올 수 있는가 (최대 3명)
- [ ] 코옵 중에 Esc를 눌러도 게임이 멈추지 않는가
- [ ] 참여한 사람이 "메인 메뉴로"를 누르면 호스트 화면에서 그 캐릭터가 사라지는가
- [ ] 호스트가 나가면 참여자는 메인 메뉴로 돌아가고 안내 문구가 나오는가

PC가 한 대뿐이라면 Godot를 두 번 실행해서, 한쪽은 방 만들기, 다른 쪽은 주소 `127.0.0.1`로 참여해 보셔도 됩니다.

## 손맛 수치를 바꾸고 싶다면
`data/player/default_movement.tres`를 에디터에서 열면 속도, 점프 높이, 슬라이딩, 턱 오르기, 마우스 감도 같은 수치를 바로 바꿀 수 있습니다. 코드를 고칠 필요는 없습니다. "더 빠르게", "점프 더 높게"처럼 말로만 알려 주셔도 제가 맞추겠습니다.

## 알려진 한계 (M1 범위 밖)
- 원격 플레이어 움직임 보간이 없어서, 네트워크가 느리면 끊겨 보일 수 있습니다. 같은 와이파이에서는 거의 티가 나지 않을 것으로 예상합니다.
- 키 재설정과 감도 설정 메뉴는 아직 없습니다.
- 캐릭터는 아직 캡슐 모양 그레이박스입니다.
