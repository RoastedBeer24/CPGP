# M1 검수 체크리스트: 첫 전투 방

> 크로스필드의 첫 목표입니다. 메뉴에서 **혼자 하기**를 누르면 전투 방에서 바로 시작합니다.
> 캐릭터 모델은 이 PC처럼 모델 파일이 있는 곳에서만 보입니다(없으면 노란 캡슐). 적은 아직 모델이 없어서 도형으로 그립니다.

## 시작
- [ ] 창 제목과 메뉴 제목이 "크로스필드"인가
- [ ] 메뉴의 **캐릭터**에서 관리자(여)·관리자(남)를 고를 수 있고, 고른 캐릭터로 시작하는가 (다음에 켜도 기억)
- [ ] 예전에 설치한 게임(CyberUniverse.exe)이 자동 업데이트로 크로스필드가 되고, 설정(에셋 키 포함)이 그대로인가 *(푸시한 뒤 확인)*

## 이동과 카메라
- [ ] 마우스로 카메라가 캐릭터 주위를 돌고, WASD가 카메라가 보는 방향 기준으로 움직이는가
- [ ] 몸이 가는 쪽으로 자연스럽게 도는가
- [ ] 휠로 카메라 거리가 바뀌는가. 벽에 붙으면 카메라가 당겨지는가
- [ ] Space 점프, 착지 동작

## 전투 (관리자)
- [ ] 왼쪽 클릭을 이어 누르면 5단계 연속 공격이 원작 동작으로 이어지는가. 마지막 일격이 묵직한가
- [ ] 공격하면 가까운 적 쪽으로 몸을 돌리고, 적 앞에서 멈추는가(지나쳐 가지 않음)
- [ ] 맞힐 때 잠깐 멈추고(타격 정지) 화면이 흔들리고, 불꽃과 피해 숫자가 뜨는가
- [ ] 싸우는 중에는 검을 들고, 전투 대기 동작을 하는가. 검을 쥔 모양이 자연스러운가
- [ ] Shift / 오른쪽 클릭: 가는 방향으로 회피, 입력이 없으면 뒤로. 회피 뒤 누르고 있으면 질주
- [ ] 회피 직후 공격하면 대시 공격
- [ ] 1: 배틀 스킬(SP 100). 맞은 적에게 주황빛 결정이 돋는가
- [ ] 궁극기 에너지가 차면 1을 길게 누르거나 Q로 궁극기. 결정이 붙은 적에게 "결정 파쇄!"와 큰 피해
- [ ] 적의 경직 게이지(노란 막대)가 차면 경직(머리 위 노란 고리), 가까이서 공격하면 처형
- [ ] 휠 클릭: 대상 고정. 카메라가 그 적을 따라가는가
- [ ] 관리자(남)도 같은 것이 다 되는가 (동작과 타격 시각만 다름)

## 적
- [ ] 돌격병: 다가와서 베기 전에 땅에 붉은 부채꼴이 깔리고 차오르는가. 차오르기 직전에 피할 수 있는가
- [ ] 사수: 거리를 두고, 쏘기 전에 땅에 직선이 깔리는가. 기둥 뒤로 숨으면 탄이 막히는가
- [ ] 중장병: 맞아도 움찔하지 않고, 내려찍기(원)에 맞으면 휘청이는가
- [ ] 예고가 끝나는 순간 회피하면 "완벽한 회피!"와 함께 잠깐 느려지는가(혼자 할 때)

## 방
- [ ] 웨이브 3개(돌격병 3 → 돌격병 2·사수 2 → 중장병·돌격병 2·사수)가 차례로 나오는가
- [ ] 다 깨면 "방 정리 완료!", 잠시 뒤 처음부터 다시 시작하는가
- [ ] 쓰러지면(혼자) "전멸" 뒤 처음부터 다시 하는가

## 협동 (같은 와이파이)
- [ ] 각자 고른 캐릭터로 보이는가
- [ ] 서로의 공격 동작, 회피, 스킬이 보이는가. 참여한 사람이 때린 적도 다치는가
- [ ] 쓰러진 동료 곁에서 F를 누르고 있으면 일으키는가(왼쪽 위에 동료 체력과 일으킨 정도)

## 화면(HUD)
- [ ] 왼쪽 아래 이름과 체력, 오른쪽 아래 SP 세 칸·배틀 스킬·궁극기, 위 가운데 웨이브와 남은 적이 읽기 쉬운가

| 캐릭터 수치 | 체력 1200, 공격력 100, SP 최대 300·초당 8, 궁극기 에너지 80, 완벽한 회피 SP 25 | kit.tres |
| 공격 배율 | 기본 0.8 / 0.9 / 0.6+0.8 / 0.6+0.9 / 2.2, 대시 1.6, 처형 6.2, 배틀 스킬 2.6, 궁극기 3+6(결정 파쇄 +4) | kit.tres |
| 추가 키 | Q 궁극기(엔드필드에는 없음), F 동료 일으키기, H 바이저 | 설정 > 조작 |
