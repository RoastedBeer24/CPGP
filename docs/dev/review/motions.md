# 검수 체크리스트: 원작 동작 활용, 무기 자리, 원작 이펙트

> 사이트(studio.warfarin.wiki)의 원작 연결 정보를 다시 확인했습니다. 전투 중 무기는 **오른손(wep_R)** 이 맞습니다.
> 지금까지 왼손에 쥔 것은 캐릭터 화면용 무기 보기 자리(wep_L)를 잘못 쓴 것이었습니다.
> 원작처럼 무기는 싸우는 동작에서만 나타나고, 나타나고 사라질 때 칼날이 차오르거나 지워집니다.
> 모델 파일이 있는 PC에서만 보입니다(모델 없이도 게임과 테스트는 돈다).

## 무기
- [ ] 로비에서 걸어 다닐 때는 무기가 없는가
- [ ] 공격하면 **오른손**에 무기가 손잡이 쪽부터 빛나며 차오르는가
- [ ] 싸우는 중에 서 있으면 무기를 든 전투 대기 자세인가
- [ ] 싸우는 중에 달리면 무기가 칼끝부터 지워지는가 (원작 자료상 이동 동작에는 무기가 없다)
- [ ] 회피하면 무기가 잠깐 사라지는가. 궁극기는 앞부분을 무기 없이 하다가 마지막 일격에 무기가 나타나는가

## 전투 시작·끝
- [ ] 방에 들어가 적이 나를 알아채면(16m 안) 등 뒤에서 무기를 꺼내 오른손으로 옮기는 동작이 나오는가
- [ ] 싸움이 끝나고(공격·피격 6초 뒤, 근처에 나를 노리는 적이 없으면) 무기를 거두는 동작이 나오는가

## 대기 동작
- [ ] 싸우지 않을 때 8초쯤 가만히 서 있으면 쉬는 자세로 바뀌는가
- [ ] 쉬는 자세로 서 있으면 12초쯤마다 특수 대기 동작 두 가지를 번갈아 하는가
- [ ] 움직이면 바로 달리기로 넘어가는가 (대기 동작이 끝날 때까지 기다리지 않음)

## 이동·맞기
- [ ] 달리다(질주하다) 손을 떼면 멈추는 동작이 나오는가. 어느 발로 멈추는지 자연스러운가
- [ ] 3m 넘게 떨어지면 무릎을 굽히며 무겁게 착지하는가
- [ ] 적에게 가볍게 맞으면 맞은 쪽(앞·뒤·왼쪽·오른쪽)에 따라 윗몸만 움찔하는가 (움직임은 막지 않음)

## 캐릭터 화면 (로비에서 C)
- [ ] 열면 캐릭터가 원작 캐릭터 화면처럼 걸어 들어와 서는가
- [ ] 캐릭터를 (패널 밖에서) 누르면 반응하는 동작을 하는가
- [ ] **무기 보기 (W)** 를 누르면 왼손에 무기를 꺼내 보여 주고, 다시 누르면 거두는가
- [ ] 캐릭터를 바꾸면 새 캐릭터가 다시 걸어 들어오는가

## 원작 이펙트 (사이트 자료로 원작 셰이더·파티클을 다시 만듦, `docs/dev/effects.md`)
- [ ] 기본 공격 1~5타, 처형(마무리 일격), 배틀 스킬에 원작 칼빛·빛 번짐·연기·불꽃이 나오는가
- [ ] 칼빛이 휘두르는 방향과 맞는가 (몸 앞, 휘두르는 쪽으로 쓸려 나감)
- [ ] 너무 밝거나 어둡지 않은가 (원작 강도가 아주 커서 밝기를 잘라 두었습니다)
- [ ] 협동: 동료의 공격에도 같은 이펙트가 보이는가
- [ ] 맞힌 자리의 흰 네모가 둥근 빛으로 바뀌었는가
- [ ] 궁극기·대시 공격은 원작 자료가 없어 예전처럼 금빛 검기가 남는가

## 아직 안 된 것
- 원작 이펙트 중 화면 왜곡·방사 흐림·디더(재질 자료가 비어 있음)와 극좌표 충격파 고리 5개는 그리지 않습니다. 사이트도 그리지 않는 것들입니다.
- 궁극기와 대시 공격은 원작 자료에 이펙트가 없습니다.
- 앉기·선물 주고받기 같은 상호작용 동작, 낙하 공격(공중 공격)은 아직 쓰지 않습니다.

## 제가 임의로 정한 것
| 항목 | 정한 값 | 바꾸려면 |
|---|---|---|
| 쉬는 자세로 바뀌기 | 가만히 8초, 특수 대기는 12초 간격으로 번갈아 | `PlayerBody.RELAX_DELAY`, `RELAX_SPECIAL_GAP` |
| 전투 자세가 되는 거리 | 나를 알아챈 적이 16m 안, 적이 잠잠해져도 2초 유지 | `Player.ALERT_RANGE`, `ALERT_COMBAT_TIME` |
| 무기가 나타나고 사라지는 시간 | 싸울 때 0.12초·0.3초, 무기 보기는 원작대로 0.6초·0.5초 | `PlayerBody.WEAPON_APPEAR_TIME` 등 |
| 대시 공격의 무기 | 오른손 (원작 자료에 대시 공격만 빠져 있음) | `CharacterAppearance.weapon_timelines` |
| 무거운 착지 | 3m 넘게 떨어졌을 때 | `PlayerBody.HEAVY_LANDING_DROP` |
| 가벼운 피격 | 윗몸만 움찔(다리는 하던 동작 그대로) | `PlayerBody.FLINCH_CLIPS` |
| 캐릭터 화면 키 | W 무기 보기, 캐릭터 누르기 반응 | `src/ui/character_screen.gd` |
| 이펙트 밝기 | 색 값을 1.5에서 자름 (원작 강도 최대 100은 원작 화면에서 하얗게 날아가게 만든 값) | `vfx_base.gdshaderinc`의 `max_brightness` |
| 이펙트가 없는 동작 | 궁극기·대시 공격은 임시 검기 유지 | `PlayerBody._update_actions` |
| 타격 빛 | 흰 네모 → 가운데가 밝은 둥근 빛(더하기) | `src/combat/hit_spark.gd` |
| 칼빛 메시의 가장자리 흐림 | 메시에 든 정점 알파(가장자리가 흐려짐)를 곱함. 사이트는 무시하지만 원작은 곱하는 것으로 보임 | `vfx_base.gdshaderinc`의 `particle_color` |
