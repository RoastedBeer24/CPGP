# 검수 체크리스트: 1인칭 다시 만들기·무기 고르기·캐릭터 고르기 (6차)

> 로비에서 **C**(캐릭터 화면)를 열면 아래쪽에 캐릭터 아이콘이, 오른쪽에 무기 목록이 있습니다. **V**로 1인칭을 켭니다.
> 아이콘은 사용자가 준 공식 초상화에서 얼굴 부분을 잘라 썼습니다(모델처럼 비공개 에셋 저장소에만 올립니다).

## 캐릭터 화면
- [ ] 아래쪽에 관리자(여)·관리자(남)·아케쿠리의 초상화 아이콘이 나란히 있고, 누르면 그 자리에서 그 캐릭터로 바뀌는가 (A·D 대신). 고른 캐릭터는 금빛 테두리와 바탕
- [ ] ← → 키로도 바꿀 수 있는가
- [ ] 무기 목록에 한손검(타르 11 ★3, O.B.J. 엣지 오브 라이트 ★4 공격력 +8%)이 있고, 누르면 든 무기가 바뀌며 "(장착 중)"이 옮겨 가는가. 무기 보기(W)로 바로 보인다
- [ ] 고른 무기가 캐릭터마다 저장되어 다음에 켜도 그대로인가, 협동에서 동료 화면에도 같은 무기가 보이는가

## 무기
- [ ] 달리거나 걸을 때는 무기가 사라지고(칼끝부터 지워짐), 공격·스킬·전투 대기 같은 싸우는 동작에서만 손에 나타나는가

## 대시 공격·소리
- [ ] 회피 직후 공격하면 원작 연계 스킬 동작이 나가는가: 관리자 "봉인 시퀀스", 아케쿠리 "섬광 돌진" (소리·보이스 포함)
- [ ] 다른 동작에서 빠진 보이스·효과음이 없는가 (원작 이동·점프·착지 동작에는 원래 소리가 없습니다. 빠진 곳이 있으면 동작 이름을 알려 주세요)

## 1인칭 (V)
- [ ] 시점이 각 캐릭터의 눈(두 눈동자 가운데)에 있는가: 관리자(남)는 키만큼 높고 관리자(여)·아케쿠리는 낮다
- [ ] 내려다보면 고개와 윗몸을 숙이며 가슴·다리·신발이 보이는가 (그림자도 같이 숙인다)
- [ ] 서 있을 때도 내 몸이 있고, 휘두를 때 팔과 칼이 보이며, 머리카락·목·옷깃이 화면을 가리지 않는가
- [ ] 옆으로 가면 다리가 가는 쪽으로 돌아가고 윗몸은 앞을 보는가, 뒤로 가면 뒷걸음질하는가 (내려다보며 확인)
- [ ] 협동에서 1인칭인 동료가 옆걸음할 때 그 동료의 다리가 가는 쪽으로 도는가 (예전에는 앞으로 달리는 다리)
- [ ] 1인칭 낙하 공격이 땅에 닿을 때 섬광이 화면을 하얗게 덮지 않는가 (1인칭에서는 이펙트가 카메라에 가까울수록 흐려진다)

## 아케쿠리
- [ ] 달리기 시작·멈추기·돌기에서 꼬리와 귀가 통통 튀는가 (너무 출렁이거나 약하면 알려 주세요)
