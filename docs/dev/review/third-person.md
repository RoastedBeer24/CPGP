# 검수 체크리스트: 3인칭과 캐릭터 모델

자동 테스트 84개가 모두 통과한 상태입니다(캐릭터 모델이 있을 때와 없을 때 모두). 직접 해 보시고 어색한 부분을 알려 주세요.

## 준비
- 캐릭터 모델은 저장소에 올리지 않습니다(재배포할 수 없는 게임 자산이라서). 이 PC에는 이미 넣어 두었습니다.
- 다른 PC에서는 [docs/assets.md](../../assets.md)의 "저장소에 없는 에셋"대로 넣습니다. 없으면 예전처럼 분홍 캡슐 몸으로 보입니다.
- 실행 파일(exe)에도 모델은 들어 있지 않습니다. exe 옆의 `characters/endministrator_f.glb`를 켤 때 읽습니다. 자동 업데이트는 exe만 바꾸므로 한 번 넣어 두면 계속 남습니다.

## 조작
| 키 | 동작 |
|---|---|
| V | 1인칭 ↔ 3인칭(오른쪽 어깨 너머) 전환 |
| ` (숫자 1 왼쪽) 누르고 있기 | 자유 시야: 마우스로 캐릭터 주변을 어느 방향으로든(위아래 거의 수직까지) 돌려 보고, 휠로 0.6~30m까지 확대·축소. 떼면 원래 시점으로 돌아옴. 둘러보는 중에도 움직이고 조준하고 쏠 수 있음(캐릭터가 보는 쪽으로 쏨) |
| 그 밖의 조작 | M2와 같음 |

바로 3인칭으로 시작하려면 `godot --path . -- --single --third-person`으로 실행합니다.

## 확인할 것
### 시점
- [ ] V를 누르면 카메라가 부드럽게 뒤로 빠지고, 다시 누르면 눈으로 돌아오는가
- [ ] 3인칭에서 캐릭터가 조준점 왼쪽에 서서 조준점을 가리지 않는가
- [ ] 벽에 등을 대면 카메라가 벽을 뚫지 않고 앞으로 당겨지는가
- [ ] 3인칭에서 쏜 탄이 조준점이 가리키는 곳에 맞는가 (허수아비로 확인)
- [ ] 1인칭은 예전과 똑같은가 (총 모델, 조준, 반동)

### 캐릭터 몸 (원본 애니메이션)
- [ ] 서 있을 때, 걸을 때(4m/s, 달리기 동작), 전력 질주할 때 동작이 자연스럽고, 발이 미끄러지지 않으며, 머리카락·코트가 함께 흔들리는가
- [ ] 평소에는 움직이는 방향으로 몸을 돌리는가. 조준(우클릭)하거나 쏘면 다리는 가는 쪽으로, 상체는 조준 쪽으로 비틀고, 뒤로 가면 앞을 본 채 뒷걸음하는가
- [ ] 점프하면 도약 → (높이서 떨어지면) 낙하 → 착지 동작이 이어지는가
- [ ] 웅크리기·웅크려 걷기: 골반을 내리고 무릎을 굽히는가 (원본에 웅크린 동작이 없어 걷기 동작에 코드로 덧입혔습니다)
- [ ] 슬라이딩: 한쪽 다리를 앞으로 뻗고 상체를 뒤로 젖히는가
- [ ] 계단: 발이 디딤판에 맞게 딛는가 (보이지 않는 경사로를 타면서 발만 계단에 맞춥니다)
- [ ] 화면 주사율이 높은 모니터(120Hz 이상)에서도 동작이 깜빡이지 않는가
- [ ] 자유 시야(`)로 달리는 모습을 옆에서 볼 수 있는가
- [ ] 권총·산탄총: 두 손으로 총을 앞으로 겨누고, 위아래를 보면 팔과 총이 따라 움직이는가
- [ ] 블레이드를 들거나 달리면 팔을 내리고 흔드는가
- [ ] 1인칭에서는 내 몸이 보이지 않고 그림자만 바닥에 비치는가

### 코옵
- [ ] 다른 사람 캐릭터가 이 모델로 보이고, 그 사람이 든 무기(권총/산탄총/블레이드)가 손에 보이는가
- [ ] 다른 사람이 쏜 탄 궤적이 그 사람 손의 총구에서 나오는가
- [ ] 내가 3인칭으로 바꿔도 다른 사람 화면에는 영향이 없는가

## 제가 임의로 정한 것 (바꾸고 싶으면 알려 주세요)
| 항목 | 지금 정한 값 | 이유 |
|---|---|---|
| 전환 키 | V | 사이버펑크 2077은 걸어 다닐 때 3인칭이 없어서, 차량 시점 전환 키를 따랐습니다 |
| 3인칭 카메라 | 머리 뒤 2.2m, 오른쪽 0.5m, 위 0.15m | 어깨 너머 슈터의 흔한 배치입니다. 조준점이 캐릭터에 가리지 않습니다 |
| 3인칭 조준 | 눈에서 조준점을 향해 쏨 | 카메라에서 쏘면 캐릭터 뒤의 물체에 맞거나, 캐릭터가 볼 수 없는 곳을 맞힐 수 있습니다 |
| 1인칭에서 내 몸 | 그림자만 보임 | 몸이 카메라를 가리지 않으면서 발밑 그림자로 존재감을 줍니다 |
| 캐릭터 동작 | 원본의 서기·걷기·달리기·질주·도약 2종·낙하·착지 2종·회피 2종. 속도 구간마다 하나를 골라 실제 속도에 맞춰 재생 | 원래 속도(걷기 1.0, 달리기 4.3, 질주 6.2 m/s)에 맞추면 발이 덜 미끄러집니다 |
| 코드로 덧입힘 | 웅크리기·슬라이딩(골반 내리기 + 다리 IK), 계단 발 맞춤, 총 겨누기, 상체 비틀기, 시선 | 원본에 웅크린 동작과 총 쥔 동작이 없습니다 |
| 몸 방향 | 평소엔 움직이는 방향, 조준·사격 후 2초는 상체만 조준 방향(다리는 가는 쪽, 최대 75° 비틀기) | 원본의 전투 걸음은 너무 느려(0.55m/s) 쓰지 않았습니다 |
| 자유 시야 | ` 누르는 동안, 휠 한 칸 1.2배, 0.6~30m, 위아래 ±85° | 설정에서 토글로 바꿀 수 있습니다 |
| 모든 플레이어의 외형 | 같은 모델 | 커스터마이즈(외형 고르기)는 아직 없습니다 |

## 수치를 바꾸고 싶다면
- **3인칭 카메라 거리, 어깨 위치, 전환 속도:** `data/player/default_movement.tres`의 "3인칭 시점"
- **캐릭터 모델 경로:** `data/player/default_appearance.tres`

## 알려진 한계
- 재질은 모델에 들어 있는 기본 재질 그대로입니다. 원작의 툰 셰이딩은 없고, 공통 툰 셰이더는 M8에서 입힙니다.
- 머리카락과 코트는 흔들리지 않습니다(물리 없음).
- 맞았을 때의 피격 판정은 예전처럼 캡슐 모양입니다. 모델의 실제 모양과 약간 다릅니다.
- 손에 든 총은 1인칭 총처럼 도형입니다.
