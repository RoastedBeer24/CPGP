# 검수 체크리스트: 시점(기본·1인칭·자유)과 이펙트 다듬기

> 기본 시점은 정해진 거리의 3인칭이고, **V**로 1인칭과 오갑니다(휠로 당기지 않음).
> 자유 시점은 **`**(숫자 1 왼쪽 키)를 **누르고 있는 동안** 쓰며, 휠로 얼굴 바로 앞까지 당길 수 있습니다.
> 설정 > 조작에서 "눌러서 켜고 끄기"로 바꿀 수 있습니다. 키는 설정 > 조작에서 바꿀 수 있습니다.

## 기본 시점 (3인칭)
- [ ] 휠을 굴려도 카메라 거리가 바뀌지 않는가
- [ ] 벽이나 기둥을 등지면 카메라가 벽 앞으로 당겨지고, 벗어나면 덜컹이지 않고 천천히 원래 거리로 돌아가는가
- [ ] 위를 올려다볼 때 카메라가 바닥을 뚫지 않는가
- [ ] 계단을 오르내리거나 점프할 때 화면이 덜 흔들리는가
- [ ] 적이 나를 알아채거나 싸우는 중에는 카메라가 조금 물러나 주변이 넓게 보이는가 (싸움이 끝나면 다시 다가옴)

## 1인칭 (V)
- [ ] V를 누르면 눈 위치에서 보는 1인칭이 되고, 다시 누르면 3인칭으로 돌아오는가 (다음에 켜도 기억)
- [ ] 1인칭에서 공격하면 보는 쪽으로 베는가
- 1인칭 3차 고침은 아래 "1인칭 다시 만들기 (3차)"에 있습니다.

## 자유 시점 (`)
- [ ] `를 누르고 있는 동안 자유 시점이고, 떼면 기본 시점으로 돌아오는가
- [ ] 설정 > 조작에서 "자유 시점을 눌러서 켜고 끄기"를 켜면 한 번 눌러 켜고 다시 눌러 끄는가
- [ ] 자유 시점에서 휠로 확대·축소가 되고, 아주 가까이 당기면 얼굴이 화면 가득 보이는가
- [ ] 가까이 당겨도 몸이 사라지지 않는가 (예전에는 가까이 가면 몸이 숨었음)
- [ ] 캐릭터 화면(로비 C)에서도 휠로 얼굴까지 당길 수 있는가 (3차부터는 원작 구도에서 얼굴 앞으로 다가감)

## 이펙트 다듬기
- [ ] 칼빛과 빛 번짐이 전보다 밝게 빛나는가 (빛 번짐을 더 받게 밝기 상한을 올림)
- [ ] 5타·처형·대시 공격에 퍼지는 충격파 고리가 보이는가 (원작의 극좌표 무늬)
- [ ] 칼빛을 따라 화면이 살짝 일렁이는가(아지랑이), 큰 타격 순간 화면이 가운데로 빨려 드는 느낌이 있는가
- [ ] 대시 공격과 궁극기에도 이펙트가 나오는가 (원작 자료에 없어 다른 동작의 원작 이펙트를 빌려 씀)
- [ ] 스킬·기본 공격 때 바닥에 작은 무늬가 격자로 깔리던 것이 부드러운 연기로 바뀌었는가 (연기 그림을 칸으로 나누지 않던 문제를 고침)

## 질주·회피 (2차, 3차에서 바뀜)
- 2차의 "Shift 질주·오른쪽 클릭 회피"는 3차에서 "Shift 짧게 회피·누르고 있으면 질주"로 바꿨습니다. 아래 3차 항목으로 확인해 주세요.

## 옷자락 (2차)
- [ ] 달릴 때 외투 자락이 뒤로 날려서, 뒤로 차는 다리가 자락을 뚫거나 걸리는 일이 줄었는가
- [ ] 질주할 때 외투가 더 크게 날리는가. 멈추면 다시 아래로 늘어지는가

## 궁극기 연출 (2차)
- [ ] 궁극기를 쓰면 원작처럼 손을 뻗는 얼굴 클로즈업 → 뒤로 돌며 빠짐 → 뒤 높은 곳에서 넓게 비추는 카메라 연출이 나오는가
- [ ] 연출이 끝나면 덜컹이지 않고 원래 카메라로 돌아오는가
- [ ] 1인칭에서 궁극기를 써도 연출 동안 얼굴이 보이는가
- [ ] 협동: 동료가 궁극기를 쓸 때 내 카메라는 그대로인가

## 1인칭 다시 만들기 (3차)
> 예전 1인칭은 카메라가 눈을 늦게 따라가서 달리면 머리 뒤로 처졌고, 숨긴 머리 아래로 목·후드·옷깃이 화면을
> 가렸습니다. 공격 동작이 몸을 크게 돌리면 외투가 화면을 덮었습니다.
- [ ] 1인칭에서 달리거나 질주해도 목·옷깃·머리카락이 화면에 보이지 않는가
- [ ] 화면이 머리 흔들림을 따라 출렁이지 않고, 몸을 낮추거나 뛰어오르는 동작에서는 시선이 같이 내려가고 올라가는가
- [ ] 1인칭에서는 내 몸이 안 보이고(바닥에 그림자는 보임), 공격할 때 휘두르는 팔과 손에 든 칼, 칼빛만 보이는가
- [ ] 팔이 카메라 바로 앞을 스칠 때 소매가 화면을 가득 덮지 않는가 (아주 가까운 곳은 점점이 지움)
- [ ] 1인칭에서 A·D로 옆으로 가도 보는 쪽을 보고, 공격도 보는 쪽으로 나가는가 (가는 쪽으로 몸이 돌지 않음)
- [ ] 1인칭에서 자동으로 노리는 적은 화면 가운데 근처(좌우 45도 안)의 적만인가. 경직된 적을 처형할 때만 시선이 그 적 쪽으로 돈다
- [ ] 1인칭에서 몸 가까이 터지는 이펙트가 화면을 하얗게 덮지 않는가 (카메라 0.5m 안은 흐리게)
- [ ] 처음 V를 누를 때 잠깐(0.05초쯤) 멈칫하는 것 말고는 끊김이 없는가 (팔 메시를 그때 한 번 만듦)

## 회피·질주 키 (3차)
- [ ] Shift를 짧게 눌렀다 떼면 회피가 나가는가 (가는 방향으로, 입력이 없으면 뒤로)
- [ ] Shift를 누르고 있으면 회피 없이 질주하고, 떼면 달리기로 돌아오는가 (질주하려고 누른 Shift로 회피가 나가지 않음)
- [ ] 마우스 오른쪽 클릭으로는 회피가 나가지 않는가
- [ ] 회피가 뗄 때 나가서 늦게 느껴지지 않는가 (0.2초보다 짧게 누르면 회피)

## 캐릭터 화면 원작 구도 (3차)
- [ ] 캐릭터 화면(로비 C)을 열면 카메라가 원작 캐릭터 화면처럼 무릎 위로 크게 잡는 구도로 부드럽게 옮겨 가는가
- [ ] 캐릭터가 오른쪽 소개 칸에 가리지 않고 왼쪽 빈 곳 가운데에 서는가
- [ ] 무기 보기(W)를 누르면 원작의 무기 보기 구도(오른쪽 아래에서 올려다봄)로 옮겨 가고, 거두면 돌아오는가
- [ ] 휠로 얼굴 앞까지 다가가고, 반대로 굴리면 원작 구도보다 뒤로 물러나 온몸이 보이는가
- [ ] Q·E나 마우스 오른쪽 끌기로 캐릭터 둘레를 도는가
- [ ] 화면을 닫으면 원래 카메라로 부드럽게 돌아오는가
- [ ] 벽을 보고 서서 캐릭터 화면을 열어도 카메라가 벽에 묻히지 않는가 (캐릭터가 카메라 쪽으로 돌아섬)

## 4차: 바이저·걷기·낙하 공격·1인칭 다듬기
### 바이저
- [ ] 바이저를 쓰고 있으면 바이저 위로 눈·속눈썹이 보이지 않는가 (H로 벗으면 눈썹이 앞머리 위로 보임)

### 걷기 (Ctrl)
- [ ] Ctrl을 누르고 있는 동안 걷고(원작 걷기 동작), 떼면 다시 달리는가
- [ ] 설정 > 조작에서 "걷기를 눌러서 켜고 끄기"를 켜면 한 번 눌러 걷고, 다시 눌러 달리는가
- [ ] 걷는 중에도 Shift를 누르고 있으면 질주하고, 떼면 다시 걷는가

### 낙하 공격 (공중에서 클릭)
- [ ] 점프한 뒤 공격하면 원작처럼 웅크렸다 뛰어올라 칼을 들고, 몸을 뒤집어 칼을 아래로 겨누고 내리꽂는가
- [ ] 높은 곳에서 하면 떨어지는 동안 칼을 아래로 겨눈 자세를 유지하는가
- [ ] 땅에 닿는 순간 빛·연기 이펙트와 충격 소리가 나고, 둘레(앞뒤 모두)의 적이 맞는가
- [ ] 착지 뒤 일어서는 동작 중에 회피(0.25초부터)·이동(0.75초부터)·다음 공격(0.55초부터)으로 끊을 수 있는가
- [ ] 관리자(남)도 같은가
- [ ] 협동: 남의 낙하 공격이 내 화면에서도 같은 동작과 이펙트로 보이는가

### 1인칭 다듬기
- [ ] 1인칭에서 달리거나 서 있을 때는 손이 화면 아래에 떠 보이지 않고, 공격하는 동안만 팔과 칼이 보이는가
- [ ] 휘두르는 팔이 어깨 쪽에서 끊겨 허공에 떠 보이지 않는가 (얼굴 바로 앞 14cm 안만 지움)

## 5차: 낙하 공격·마무리 공격·무기 다듬기
- [ ] 낙하 공격에서 내리꽂는 칼빛(빛 기둥)과 착지 섬광·연기가 나오는가 (점프 높이에서 바로 내리꽂아도 칼빛이 남음), 착지할 때 화면이 흔들리는가
- [ ] 적 바로 위로 내리꽂아도 적의 머리 위가 아니라 땅에 내려서는가 (예전에는 적 위에 선 채 움직여 공중에 뜬 것처럼 보였음)
- [ ] 5타(마무리 일격)·처형·대시 공격처럼 몸을 크게 돌리는 공격이 끝날 때 몸이 원래 방향으로 휙 튀지 않는가 (원작처럼 돌아간 방향으로 일어섬)
- [ ] 1타를 한 번만 쳐도 원작처럼 다시 앞을 보며 끝나는가
- [ ] 연속 공격 중 다음 공격이 목표(없으면 카메라가 보는 쪽)로 빠르게 돌아서며 나가는가
- [ ] 싸우는 동안에는 달리거나 회피해도 무기를 손에 든 채로 있고, 무기가 지워졌다 다시 나타나기를 되풀이하지 않는가
- [ ] 전투가 끝나면 거두는 동작 중에 칼끝부터 0.5초에 걸쳐 지워지는가, 싸움 밖에서 회피할 때는 무기가 나오지 않는가
- [ ] 캐릭터 화면이 열려 있는 동안 왼쪽 아래 이름·체력과 위쪽 로비 안내가 숨는가

## 그 밖에
- [ ] 화면 확인용 캡처를 하는 동안 창이 뜨거나, 키 입력·마우스를 가져가거나, 소리가 나지 않는가 (Claude 작업 중)
