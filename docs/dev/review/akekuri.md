# 검수 체크리스트: 아케쿠리 추가

> 로비에서 **C**(캐릭터 화면)를 열고 ◀ ▶로 아케쿠리(3/3)를 고르세요. 메뉴의 캐릭터 고르기에서도 고를 수 있습니다.
> 원작 아케쿠리(chr_0019_karin)의 모델·동작·무기(O.B.J. 엣지 오브 라이트)·소리·보이스·이펙트·카메라 연출을 씁니다.

## 모습
- [ ] 붉은 머리, 여우 귀와 꼬리, 흰색·검은색 옷의 형광 노란 장식이 원작처럼 보이는가 (만화풍 그늘, 외곽선, 얼굴 그림자)
- [ ] 겹쳐 그려진 메시(먼 거리용 저해상도 메시)나 하늘색 줄 같은 이상한 그림이 없는가
- [ ] 캐릭터 화면이 원작 구도로 잡히고, 무기 보기(W)는 오른손에 무기를 든 원작 구도인가
- [ ] 걸어 들어오기·대기·쓰다듬기 반응·쉬는 자세·특수 대기 동작이 나오는가

## 싸움
- [ ] 기본 공격 4연속(진취의 검날): 빙글 돌며 베고, 4타(마무리 일격)는 크게 내달려 벤다. 끝난 뒤 몸이 튀지 않는가
- [ ] 배틀 스킬(열정 분출, 1): 불꽃 칼빛과 함께 돌진하며 두 번 벤다. 맞히면 SP를 돌려받는다
- [ ] 궁극기(소대, 집합!, Q 또는 1 길게): 원작 카메라 연출(얼굴 → 위에서 → 신호탄)과 세 번의 폭발이 나오는가
- [ ] 궁극기를 쓰면 곁(8m 안)의 동료와 나의 SP가 100 오르는가 (협동에서 동료 화면의 SP도 오름)
- [ ] 처형(경직된 적 가까이서 공격): 두 바퀴 넘게 돌며 베는가
- [ ] 낙하 공격(점프 뒤 공격): 뛰어올라 한 바퀴 돌고 내리꽂으며, 땅에 닿을 때 이펙트가 나오는가
- [ ] 회피·질주·걷기·맞음·쓰러짐 동작이 어색하지 않은가 (회피는 원작 공통 동작)
- [ ] 무기는 싸우는 동안 오른손에 들고 있고, 꺼낼 때는 등 뒤에서 꺼내는가
- [ ] 동작마다 원작 소리·보이스(설정의 음성 언어)가 나오는가
