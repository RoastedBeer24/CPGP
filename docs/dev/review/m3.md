# M3 검수 체크리스트: 적 AI와 잠입

자동 테스트 127개가 모두 통과한 상태입니다. 직접 해 보시고 들키는 정도, 적의 움직임이 어색한 부분을 알려 주세요.

## 조작 (새로 생긴 것)
| 키 | 동작 |
|---|---|
| F | 상호작용: 뒤에서 **제압**, 쓰러진 적 **몸 들기**, 들고 있을 때 **내려놓기**, 컨테이너 옆에서 **숨기기** |
| Ctrl / C | 웅크리기. 웅크려 걸으면 **발소리가 나지 않고**, 적에게 절반 속도로 발견됩니다 |

F 키는 설정 → 조작 → 키 설정에서 바꿀 수 있습니다.

## 시험장에 새로 생긴 곳
- **잠입 구역:** 시작 위치에서 **왼쪽(서쪽) 벽의 입구**로 들어갑니다. 입구 위에 "잠입 구역" 글씨가 있습니다.
  - 순찰하는 경비 넷, 중장갑병 하나(가운데 창고 앞, 주황 바이저, 몸이 큼), 제자리를 지키는 보초 하나가 있습니다.
  - 엄폐용 상자, 창고 건물, 시체를 숨길 **초록색 컨테이너** 셋이 있습니다.
  - 쓰러진 적은 60초 뒤 처음 자리에서 되살아납니다.
- **경비병 구역**(남동쪽)의 두 경비도 새 AI로 바뀌었습니다. 이제 보자마자 쏘지 않고, 알아채는 데 시간이 걸립니다.

## 적의 머리 위 표시
| 표시 | 뜻 |
|---|---|
| 흐린 흰 `?` | 무언가 보이기 시작함. 진할수록 들키기 직전 |
| 노란 `?` | 의심: 그쪽을 돌아보고 확인하러 옴 |
| 주황 `!` | 수색: 총소리·시체·동료의 호출로 그 근처를 뒤짐 |
| 빨간 `!` | 전투: 엄폐 지점으로 움직이며 쏘고, 근처 동료를 부름 |
| 회색 "기절" | 제압당해 쓰러짐 |

## 확인할 것
### 감지
- [ ] 정면에서 보이면 바로 쏘지 않고 `?`가 진해지다가 전투로 넘어가는가
- [ ] 멀리 있을수록, 웅크릴수록 늦게 알아채는가
- [ ] 벽이나 상자 뒤에 숨으면 보지 못하는가
- [ ] 적 뒤에서 달리면 발소리를 듣고 돌아보는가. 웅크려 걸으면 바로 뒤까지 가도 모르는가
- [ ] 총을 쏘면 근처(약 35m) 적들이 소리 난 곳으로 수색하러 오는가

### 경계 단계
- [ ] 의심 → 확인하러 왔다가 아무것도 없으면 원래 순찰로 돌아가는가
- [ ] 한 명이 전투에 들어가면 근처(20m) 동료도 수색하러 오는가
- [ ] 전투 중 숨어서 5초쯤 안 보이면 수색으로 바뀌고, 15초쯤 뒤 경계를 푸는가
- [ ] 전투 중인 적이 상자 옆 엄폐 지점으로 움직이며 쏘는가
- [ ] 뒤돌아 있는 적을 쏘면 바로 쏜 사람을 알아채는가

### 은신
- [ ] 적 뒤에 바짝 붙으면 "F: 제압"이 뜨고, 누르면 쓰러지는가 (전투 중인 적은 안 됨)
- [ ] 쓰러진 적 앞에서 "F: 몸 들기" → 어깨에 메고 느리게 움직이는가. 들고 있는 동안은 쏠 수 없는가
- [ ] 컨테이너 옆에서 "F: 숨기기"를 누르면 몸이 사라지는가
- [ ] 바닥에 둔 몸을 다른 경비가 보면 수색을 시작하는가. 숨긴 몸은 못 찾는가
- [ ] 중장갑병은 총에 잘 안 죽는가 (장갑 80, 체력 220). 뒤에서 제압은 되는가

### 코옵
- [ ] 다른 사람 화면에도 적의 `?`, `!`, 쓰러진 몸, 들고 가는 몸이 똑같이 보이는가
- [ ] 다른 사람이 제압하거나 몸을 숨겨도 내 화면에 반영되는가

## 수치를 바꾸고 싶다면
- **적:** `data/enemies/guard.tres`(경비), `heavy.tres`(중장갑병), `guard_arena.tres`(경비병 구역). 시야, 발견 속도, 웅크림 효과, 수색 시간, 피해 등
- **소리 크기:** `src/ai/stealth_noise.gd` 맨 위의 숫자

"좀 더 늦게 들키게", "중장갑병 더 단단하게"처럼 말로만 알려 주셔도 제가 맞추겠습니다.
