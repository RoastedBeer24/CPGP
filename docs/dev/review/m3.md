# M3 검수 체크리스트: 한 판(작전), 로비, 무기·소리

> 메뉴에서 **혼자 하기**나 **방 만들기**를 누르면 이제 로비에서 시작합니다. 로비에서 [Enter]로 작전에 나가면
> 방 다섯 개(전투 → 전투 → 중간 보스 → 전투 → 최종 보스)를 차례로 깹니다.
> 무기 모델과 소리는 원작 자산이라 이 PC처럼 파일이 있는 곳에서만 나옵니다(없으면 코드로 만든 검, 소리 없음).

## 로비
- [ ] 혼자 하기·방 만들기 모두 로비(격납고, 북쪽에 빛나는 출발 게이트)에서 시작하는가
- [ ] 로비에서 캐릭터로 걸어 다닐 수 있는가
- [ ] [C] 캐릭터 화면: 카메라가 캐릭터를 앞에서 비추고, 오른쪽에 소개·수치·기술 설명이 나오는가
- [ ] 캐릭터 화면에서 ◀ ▶(또는 A·D)로 관리자(여)·(남)을 바꾸면 그 자리에서 바로 바뀌는가 (다음에 켜도 기억)
- [ ] 캐릭터 화면에서 휠로 가까이·멀리, 마우스 오른쪽 끌기나 Q·E로 둘러볼 수 있는가
- [ ] 방장이 [Enter]를 누르면 출발하는가. 참여한 사람 화면에는 "방장이 출발하면 시작합니다"
- [ ] 협동: 참여한 사람이 캐릭터를 바꾸면 방장 화면에서도 바뀌는가

## 작전
- [ ] 위에 "작전 n/5 · 방 이름 · 웨이브 · 남은 적"이 나오는가
- [ ] 방을 깨면 "보상을 고르세요"와 카드 세 장이 나오고, 클릭이나 1·2·3으로 고르는가 (고르는 동안 캐릭터가 움직이지 않음)
- [ ] 고른 보상이 실제로 듣는가 (예: 날 선 칼날 → 피해 숫자가 커짐, 강화 외골격 → 체력 막대가 늘고 회복)
- [ ] 협동: 모두 고르면 다음 방으로 가는가 (40초 안에 안 고르면 그냥 넘어감)
- [ ] 방 B(가운데 기둥)와 보스 방(넓은 전투장)이 따로 있는가
- [ ] 중간 보스 "중장병 대장": 화면 위에 보스 체력·경직 막대, 내려찍기(원)·쓸기·돌진(땅에 긴 띠)
- [ ] 최종 보스 "약탈자 우두머리": 체력이 절반 아래가 되면 "(격노)" 표시, 붉게 빛나고 예고가 짧아지는가. 충격파(직선 탄)
- [ ] 최종 보스를 잡으면 "작전 완료!", 잠시 뒤 로비로 돌아가는가
- [ ] 모두 쓰러지면 "작전 실패", 로비로 돌아가는가. 보상은 사라지는가
- [ ] 작전 중에 다른 사람이 참여하려 하면 "작전이 진행 중입니다" 안내가 나오는가

## 무기·소리·검기
- [ ] 관리자가 원작 무기 **타르 11**을 왼손에 드는가(원작 연결 정보가 왼손). 쥔 모양이 자연스러운가
- [ ] 공격·배틀 스킬·궁극기·처형·회피에 원작 효과음과 보이스가 동작에 맞춰 나오는가
- [ ] 설정 > 게임 > **보이스 언어**(한국어·일본어·영어·중국어)가 바로 반영되는가
- [ ] 휘두를 때 칼날 자리에 빛의 띠(검기)가 남는가. 배틀 스킬·궁극기는 주황빛
- [ ] 소리 크기가 적당한가 (원작 믹싱보다 조금 키웠습니다)

## 카메라
- [ ] 휠로 아주 가까이(0.8m, 얼굴 높이)부터 멀리(18m)까지 당기고 밀 수 있는가
- [ ] 위·아래로 더 많이 돌아가는가

## 아직 안 된 것
- **원작 이펙트(칼빛·파티클):** 받은 이펙트 파일에는 모양과 텍스처는 있지만 어느 모양에 어떤 재질을 쓰는지가 비어 있고, 원작 전용 셰이더도 없습니다. 원작 셰이더를 Godot로 다시 만드는 작업이 따로 필요합니다. 그 전까지는 검기(빛의 띠)로 대신합니다.
- 적은 아직 모델이 없어서 도형으로 나옵니다.
