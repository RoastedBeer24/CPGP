## 모습과 동작
- [ ] 다섯 적이 원작 모습으로 나오는가 (모델이 없는 PC에서는 예전 도형 몸)
- [ ] 서 있기·쫓아오기(달리기·걷기)·맞음·경직(무너졌다가 무너진 채)·쓰러짐 동작이 어색하지 않은가
- [ ] 쓰러진 뒤 쓰러지는 동작을 다 보이고 땅으로 가라앉는가
- [ ] 맞으면 하얗게 번쩍이고(움찔하는 적), 로댄은 체력 절반 아래에서 붉은빛이 도는가 (격노)
- [ ] 로댄처럼 큰 적이 바로 옆에 붙어도 카메라 앞의 몸이 화면을 가리지 않는가 (아주 가까운 곳은 점점이 지움)

## 공격
- [ ] 공격 동작과 땅의 예고(부채꼴·원·띠)가 맞는가: 예고가 다 차는 순간 동작도 내리치는가
- [ ] 로댄의 내려찍기는 땅에서 높이 뛰어올랐다가 예고가 끝날 때 내리꽂는가 (예고 1.5초)
- [ ] 저격수가 쏘는 순간과 탄이 나가는 순간이 맞는가
- [ ] 적의 공격이 지나치게 멀리서 맞거나, 닿았는데 안 맞는 일이 없는가 (덩치가 커져 판정 거리를 늘렸다)

## 로댄 소리 (추가)
- [ ] 로댄이 싸움을 걸 때 도발 보이스가 나오고, 체력 절반 아래로 격노할 때 다른 도발 보이스가 나오는가 (설정의 음성 언어)
- [ ] 내려찍기는 뛰어오를 때 외치고 내리꽂는 순간 충격음이 나는가, 충격파도 외침과 충격음이 맞는가
- [ ] 휘두르기·돌진에 휘두르는 소리가 칼(주먹)이 지나가는 순간 나는가

## 아직 없는 것
- 일반 적의 소리·보이스: 꾸러미에 없다(로댄·네파리스에만 있다). 로댄 소리는 넣었다.
- 원작 적 이펙트: 꾸러미에 자료가 없다.
- 나머지 12종(립터스크, 침투자, 돌격수, 집행자, 염술사, 파괴자, 사수, 정예들, 네파리스 두 형태)은 아직 쓰지 않는다.

## 제가 임의로 정한 것
| 항목 | 정한 값 | 바꾸려면 |
|---|---|---|
| 적 고르기 | 돌격병 → 약탈자, 사수 → 저격수(쏘는 동작이 있는 쪽), 중장병 → 처형자, 중장병 대장 → 처형자 · 정예, 약탈자 우두머리 → 로댄 | `data/enemies/*.tres`의 `model_file` |
| 크기 | 원작 크기 그대로(약탈자 2.1m, 저격수 2.05m, 처형자 2.7m, 정예 2.8m, 로댄 3.1m), 몸 두께 0.5~1.0m | 같은 파일의 `height`, `radius` |
| 공격 동작 | 약탈자 attack_01·02, 저격수 attack_01(사격)·02(밀치기), 처형자 skill_01·03, 정예 skill_01·05_01·09(돌진), 로댄 skill_04·skill01_01_attack·skill03_end·skill06_01 | `tools/extract_enemy.py`의 `ENEMIES` |
| 판정 거리 | 약탈자 2.8~3.0m, 처형자 3.6~3.8m (예전 2.4·3.4~3.6m) | 같은 파일의 `reach` |
| 쓰러진 몸 | 4초 남음(예전 2.5초), 2.6초부터 1.2초 동안 가라앉음 | `Enemy.CORPSE_TIME`, `EnemyBody.SINK_*` |
| 로댄 소리 | 원작 소리는 충격파(skill03_end)와 다른 기술·도발에만 있어서, 내려찍기는 충격파의 외침·충격음을, 휘두르기·돌진은 두 번째 기술의 휘두르는 소리를 타격 시각에 맞춰 빌려 씀. 싸움을 걸 때 1형태 도발, 격노할 때 2형태 도발 보이스 | `tools/extract_enemy.py`의 `SOUNDS` |
