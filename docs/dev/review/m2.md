# M2 검수 체크리스트: 전투 기초

자동 테스트 67개가 모두 통과한 상태입니다. 직접 해 보시고 손맛이 어색한 부분을 알려 주세요.

## 조작 (사이버펑크 2077 기본값)
| 키 | 동작 |
|---|---|
| 마우스 왼쪽 | 공격 (총 발사, 블레이드 휘두르기) |
| 마우스 오른쪽 (누르고 있기) | 조준 (시야가 좁아지고 퍼짐·반동이 줄어듦, 이동이 느려짐) |
| R | 재장전 (빈 탄창으로 쏘면 자동 재장전) |
| 1 / 2 / 3, 마우스 휠 | 무기 교체 (권총 / 산탄총 / 팔 내장 블레이드) |
| 방향키 두 번 빠르게 (예: D D) | 그 방향으로 회피 |
| 그 밖의 이동 | M1과 같음 (WASD, Shift, Ctrl, Space, Esc, F3) |

## 시험장에 새로 생긴 곳
- **사격장:** 시작 위치에서 **뒤로 돌면** 있습니다. 청록색 선이 사격선입니다.
  - 5m, 10m, 15m 거리에 허수아비가 하나씩 있습니다.
  - 6m 거리에 장갑 100짜리 허수아비가 있습니다. 같은 무기로도 피해가 절반만 들어갑니다.
  - 허수아비는 쓰러지면 2초 뒤 되살아납니다.
- **경비병 구역:** 시작 위치에서 **오른쪽 뒤편(남동쪽)**에 있습니다.
  - 엄폐물 뒤에 경비병 둘이 있습니다. 15m 안에서 보이면 돌아서서 쏩니다.
  - 경비병은 쓰러지면 10초 뒤 되살아납니다.

## 확인할 것
### 사격
- [ ] 권총: 몸통 22, 머리 44 피해. 쏘는 느낌과 반동이 적당한가
- [ ] 산탄총: 가까이서 강하고 멀면 약한가. 한 번에 9발이 퍼지는 느낌이 괜찮은가
- [ ] 블레이드: 가까이(약 2.6m)에서만 베이고 피해 45. 휘두르는 동작이 시원한가
- [ ] 맞히면 조준점 주변에 명중 표시가 뜨는가 (머리는 노란색, 처치는 빨간색)
- [ ] 맞힌 자리에 피해 숫자가 뜨는가 (머리는 노랗고 크게)
- [ ] 조준(우클릭)하면 시야가 좁아지고 총이 화면 가운데로 오는가
- [ ] 탄약 표시와 재장전이 자연스러운가

### 적과 피격
- [ ] 경비병이 나를 보고 돌아서서 쏘는가. 엄폐물 뒤에 숨으면 쏘지 않는가
- [ ] 맞으면 화면이 붉게 번쩍이고 체력이 줄어드는가
- [ ] 죽으면 "사망했습니다" 화면이 나오고, 3초 뒤 시작 지점에서 다시 시작하는가

### 회피
- [ ] 방향키 두 번으로 빠르게 피하는 느낌이 괜찮은가. 너무 멀거나 짧지 않은가

### 코옵
- [ ] 다른 사람이 쏜 탄 궤적이 보이는가
- [ ] 다른 사람이 허수아비를 맞히면 내 화면의 허수아비 체력도 줄어드는가
- [ ] 같은 편끼리는 총에 맞아도 피해가 없는가

## 제가 임의로 정한 것 (바꾸고 싶으면 알려 주세요)
| 항목 | 지금 정한 값 | 이유 |
|---|---|---|
| 탄약 | 탄창만 있고 예비탄은 무한 | 인벤토리(M5)가 생기면 예비탄과 탄약 줍기를 넣을 예정 |
| 아군 사격 | 없음 | 가족끼리 하는 코옵이라 실수로 서로 맞히는 스트레스를 없앰 |
| 사망 후 | 3초 뒤 시작 지점에서 부활 | 임시입니다. 저장 시스템(M6)에서 "마지막 저장 지점에서 다시 시작"으로 바꿀 예정 |
| 회피 입력 | 방향키 두 번 | 사이버펑크 2077 기본값과 같음 |
| 무기 수치 | 권총 22(머리 ×2), 산탄 12×9발, 블레이드 45 | 처음 잡아 본 값입니다. 손맛 확인 후 조정 |

## 수치를 바꾸고 싶다면
- **무기:** `data/weapons/` 아래 `.tres` 파일. 피해, 연사 속도, 퍼짐, 반동, 탄창, 재장전 시간 등
- **이동과 회피:** `data/player/default_movement.tres`

"산탄총 더 세게", "반동 줄여"처럼 말로만 알려 주셔도 제가 맞추겠습니다.

## 알려진 한계 (M2 범위 밖)
- 경비병은 제자리에서 돌아서 쏘기만 합니다. 순찰, 경계, 수색, 엄폐 같은 진짜 AI는 M3입니다.
- 무기와 캐릭터는 아직 도형입니다. 소리도 아직 없습니다. 모두 M8에서 공개 에셋으로 바꿉니다.
- 다른 플레이어의 손에 든 무기는 아직 보이지 않습니다. 탄 궤적만 보입니다.
