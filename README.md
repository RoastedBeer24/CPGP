# CyberUniverse: 사이버펑크 1인칭 액션 RPG

1인칭 사이버펑크 액션 RPG(구역형 반오픈월드, 싱글 + LAN 코옵) 프로젝트입니다. 엔진은 Godot 4.5이고, 아트풍은 서브컬처풍입니다. 가족끼리 즐기기 위한 비상업 프로젝트입니다.

현재 단계: **M0 (기반) 완료**, 다음은 M1 (플레이어 컨트롤러 + 네트워크 뼈대)
