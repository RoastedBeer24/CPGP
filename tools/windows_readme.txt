크로스필드 (Crossfield, Windows)
================================

실행
----
Crossfield.exe 를 더블클릭하면 됩니다. 설치는 필요 없습니다.
(예전에 CyberUniverse 로 설치했다면 CyberUniverse.exe 가 그대로 크로스필드로 바뀝니다.)

처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다.
서명되지 않은 개인 제작 프로그램이라 뜨는 창입니다.
[추가 정보] -> [실행] 을 누르면 됩니다.

압축은 바탕 화면이나 문서 폴더처럼 마음대로 쓸 수 있는 곳에 푸세요.
(Program Files 안에 두면 자동 업데이트가 파일을 바꾸지 못합니다.)

조작 (엔드필드 PC판과 같음)
---------------------------
WASD 이동, 마우스 카메라(휠: 거리)
마우스 왼쪽: 공격 (경직된 적 가까이서는 처형)
마우스 오른쪽 또는 Shift: 회피 (누르고 있으면 질주)
1: 배틀 스킬 (궁극기가 차 있으면 길게 눌러 궁극기), Q: 궁극기
마우스 가운데: 대상 고정, Space: 점프, F(누르고 있기): 쓰러진 동료 일으키기
Esc: 메뉴 (키는 설정에서 바꿀 수 있습니다)

캐릭터 모델
-----------
이 폴더 안에 characters\endministrator_f.glb, characters\endministrator_m.glb 가 있어야
캐릭터 모습이 보입니다. 없으면 노란 캡슐 모양으로 나옵니다.
설정 > 게임 의 "에셋 키"를 넣어 두면 모델도 자동으로 받습니다.

자동 업데이트
-------------
게임을 켜면 새 버전이 있는지 확인하고, 있으면 왼쪽 아래에 받는 중이라고 나옵니다.
메뉴 화면에 있으면 다 받은 뒤 저절로 다시 시작되고, 게임 중이면 게임을 끝낼 때 설치됩니다.
characters 폴더는 업데이트해도 그대로 남습니다.
인터넷이 안 되면 그냥 지금 버전으로 실행됩니다.

코옵 (같은 와이파이 / 공유기)
-----------------------------
1. 한 사람이 "방 만들기"를 누릅니다.
   처음에 Windows 방화벽 창이 뜨면 "개인 네트워크"에 체크하고 [허용]을 누릅니다.
2. 방을 만든 사람이 Esc를 누르면 "방 주소"(예: 192.168.0.12)가 보입니다.
3. 다른 사람은 그 주소를 입력하고 "참여하기"를 누릅니다. 최대 3명.
   각자 메뉴에서 고른 캐릭터로 들어갑니다.

문제가 생기면
-------------
Crossfield.console.exe 로 실행하면 검은 창에 기록(로그)이 함께 보입니다.
기록 파일 위치: %APPDATA%\Godot\app_userdata\Crossfield\logs\godot.log
이 파일을 보내 주시면 원인을 찾는 데 도움이 됩니다.
